Play Midnight Club 3 on your PC

GitHub Pages hosts the single-player launcher. Chrome uses your own Xbox disc files and the matching browser build from your computer. The launcher interface is in English. The game's languages depend on your disc.

To prepare the files once: Ubuntu 24.04 or Windows with WSL 2, with about 25 GB free for the SDK, disc copy and build. To play: recent desktop Chrome with WebAssembly threads and SIMD, WebGL 2, and enough memory. If you already have the prepared files, go to step 4.

Back to the launcher

1. Copy your own Xbox disc

Use the original Xbox release of DUB Edition Remix (Europe or USA). The original DUB Edition for Xbox (Europe or USA) also works. A standard PC DVD drive usually sees only the video partition.

  1. If you already have your own full ISO or XISO backup, keep it. Step 3 extracts it.
  2. If you have the physical disc and an original Xbox with an FTP-enabled custom dashboard, insert the disc and open that dashboard. Connect the Xbox and PC to your home network. In an FTP client on your PC, enter the Xbox IP shown on the dashboard and its FTP credentials, open the DVD drive D: and copy its entire contents. The copied folder should contain default.xbe at its top level.
  3. You can also make a full ISO with a compatible reflashed DVD drive. See xemu's original Xbox disc backup guide.

2. Set up Ubuntu and Emscripten

On Windows 10 or 11, open PowerShell as administrator and run the following command. Restart if prompted, open Ubuntu 24.04 from Start and create your Ubuntu username and password. On Ubuntu, go straight to the next command block. Microsoft WSL guide

wsl --install -d Ubuntu-24.04

Run these commands in the Ubuntu terminal. Keep the checkout under your Ubuntu home directory.

sudo apt update
sudo apt install -y git make
cd ~
git clone https://github.com/sPROFFEs/mc3-web-sites.git
cd mc3-web-sites
make setup GAME=remix

git clone https://github.com/emscripten-core/emsdk.git ~/emsdk
cd ~/emsdk
./emsdk install latest
./emsdk activate latest
source ~/emsdk/emsdk_env.sh
cd ~/mc3-web-sites

For the original DUB Edition, use GAME=dub in every make command. Emscripten SDK installation

3. Extract and build

If you have an ISO, copy it to your Ubuntu home folder as mc3.iso and run the first command below. On Windows, run cd ~ && explorer.exe . in Ubuntu to open that folder, then return to the project with cd ~/mc3-web-sites. If you already copied the extracted files, put them in game-remix/ inside the project so that game-remix/default.xbe exists. In that case, start at make lift.

make extract GAME=remix ISO="$HOME/mc3.iso"
make lift GAME=remix
make web GAME=remix

The first conversion and compilation can take several minutes. The Remix produces mcdub3remix.js and mcdub3remix.wasm in work-remix/build-web/. DUB uses the disc folder game/ and produces mcdub3.js and mcdub3.wasm in work-dub/build-web/.

4. Open the game

To play on another computer, copy the extracted disc folder and the matching .js, .wasm and optional .worker.js. You can transfer them in a ZIP. Unzip it on the destination computer and use Chrome there. This works with the same build on compatible Windows, macOS and Linux desktops, with no recompilation or WSL on the destination.

  1. Return to the launcher in desktop Chrome. The first visit reloads once to enable WebAssembly threads.
  2. Click Choose build files and select both the .js and .wasm files together. Include the matching .worker.js if the build created one.
  3. Click Choose disc folder, select game-remix/ or game/, approve Chrome's folder access and press Play. Select both inputs again after reloading. On Windows, run explorer.exe . from the project folder to locate the files. If the Chrome picker cannot open the WSL path, copy the files and disc folder to a normal Windows folder first. Find WSL files in Windows Explorer

Click the game to give it keyboard focus. Enter is Start, the arrow keys drive and Space is the handbrake. The Controls tab has the full layout.

5. Save and back up your progress

Save inside the game. Progress is kept in Chrome's private storage for this site and Chrome profile. It survives reloads. Use Saves → Back up to folder to write a dated ZIP to mc3-saves-backup/ in a folder you choose, including the extracted game folder. Click it whenever you want a fresh copy. Export all saves downloads a ZIP if Chrome cannot write to your chosen folder.

To restore a profile, unzip the backup and use Saves → Import save with the .mc3Remix or .mc3 file under UDATA/ before pressing Play. Clearing site data removes Chrome's copy, so keep a separate ZIP.

If you get stuck

  • Missing default.xbe means the wrong folder was selected or the copy is incomplete. Select the folder containing that file and all the disc data.
  • If the build or disc is rejected, check the game edition and use the unmodified default.xbe from your own compatible Xbox disc. If emcc is missing, run source ~/emsdk/emsdk_env.sh in the current terminal.
  • If WebAssembly threads are unavailable, open the launcher directly in an up-to-date desktop Chrome window and reload normally.

Midnight Club 3 auf dem PC spielen

GitHub Pages stellt den Einzelspieler-Launcher bereit. Chrome verwendet die Dateien deiner eigenen Xbox-Disc und die passende Browser-Version auf deinem Computer. Der Launcher ist auf Englisch. Die Spielsprachen hängen von deiner Disc ab.

Für die einmalige Vorbereitung: Ubuntu 24.04 oder Windows mit WSL 2 und etwa 25 GB freier Platz für SDK, Disc-Kopie und Build. Zum Spielen: ein aktueller Desktop-Chrome mit WebAssembly-Threads und SIMD, WebGL 2 und ausreichend Arbeitsspeicher. Hast du die fertigen Dateien schon, gehe zu Schritt 4.

Zurück zum Launcher

1. Die eigene Xbox-Disc kopieren

Verwende DUB Edition Remix für die erste Xbox (Europa oder USA). Auch die ursprüngliche DUB Edition für Xbox (Europa oder USA) wird unterstützt. Ein gewöhnliches PC-DVD-Laufwerk sieht meist nur die Videopartition.

  1. Hast du bereits eine eigene vollständige ISO- oder XISO-Sicherung, verwende sie in Schritt 3.
  2. Wenn du die Disc und eine Xbox mit einem FTP-fähigen alternativen Dashboard hast, lege die Disc ein und öffne das Dashboard. Verbinde Xbox und PC mit deinem Heimnetz. Gib im FTP-Programm auf dem PC die Xbox-IP aus dem Dashboard und dessen FTP-Zugangsdaten ein. Öffne das DVD-Laufwerk D: und kopiere den gesamten Inhalt. Die Datei default.xbe muss direkt im kopierten Ordner liegen.
  3. Mit einem kompatiblen DVD-Laufwerk mit angepasster Firmware kannst du eine vollständige ISO erstellen. Xbox-Discs sichern (xemu, Englisch)

2. Ubuntu und Emscripten einrichten

Öffne unter Windows 10 oder 11 die PowerShell als Administrator. Führe den folgenden Befehl aus, starte Windows bei Aufforderung neu und öffne Ubuntu 24.04 im Startmenü. Lege deinen Ubuntu-Benutzernamen und dein Passwort an. Unter Ubuntu kannst du direkt mit dem nächsten Befehlsblock beginnen. WSL-Anleitung von Microsoft

wsl --install -d Ubuntu-24.04

Führe diese Befehle im Ubuntu-Terminal aus. Lege das Projekt in deinem Ubuntu-Heimverzeichnis ab.

sudo apt update
sudo apt install -y git make
cd ~
git clone https://github.com/sPROFFEs/mc3-web-sites.git
cd mc3-web-sites
make setup GAME=remix

git clone https://github.com/emscripten-core/emsdk.git ~/emsdk
cd ~/emsdk
./emsdk install latest
./emsdk activate latest
source ~/emsdk/emsdk_env.sh
cd ~/mc3-web-sites

Für die ursprüngliche DUB Edition ersetze GAME=remix in allen make-Befehlen durch GAME=dub. Emscripten-SDK installieren (Englisch)

3. Disc entpacken und Spiel kompilieren

Kopiere deine ISO als mc3.iso in dein Ubuntu-Heimverzeichnis und führe den ersten Befehl unten aus. Unter Windows öffnet cd ~ && explorer.exe . den Ordner im Explorer. Wechsle danach mit cd ~/mc3-web-sites zurück ins Projekt. Wenn du die Disc schon als Dateien kopiert hast, lege sie im Projekt unter game-remix/ ab. Prüfe, ob game-remix/default.xbe vorhanden ist, und beginne mit make lift.

make extract GAME=remix ISO="$HOME/mc3.iso"
make lift GAME=remix
make web GAME=remix

Die erste Konvertierung und Kompilierung kann mehrere Minuten dauern. Remix erzeugt mcdub3remix.js und mcdub3remix.wasm in work-remix/build-web/. Für DUB heißt der Disc-Ordner game/. Die Ausgabe besteht aus mcdub3.js und mcdub3.wasm in work-dub/build-web/.

4. Das Spiel starten

Für einen anderen Computer kopiere den entpackten Disc-Ordner und die passenden Dateien .js, .wasm und gegebenenfalls .worker.js. Du kannst alles als ZIP übertragen und auf dem Zielrechner entpacken. Derselbe Build läuft in Chrome auf kompatiblen Windows-, macOS- und Linux-Rechnern. Auf dem Zielrechner brauchst du weder WSL noch einen neuen Build.

  1. Öffne den Launcher in Chrome auf deinem PC. Beim ersten Besuch lädt die Seite einmal neu, um WebAssembly-Threads zu aktivieren.
  2. Klicke auf Choose build files und wähle .js und .wasm gemeinsam aus. Falls vorhanden, wähle auch die passende .worker.js aus.
  3. Klicke auf Choose disc folder, wähle game-remix/ oder game/, erlaube Chrome den Ordnerzugriff und drücke Play. Nach dem Neuladen wählst du beide Eingaben erneut. Unter Windows öffnet explorer.exe . im Projekt den Explorer. Wenn Chrome den WSL-Pfad nicht öffnen kann, kopiere die Dateien und den Disc-Ordner zuerst in einen normalen Windows-Ordner. WSL-Dateien im Explorer finden

Klicke auf das Spielbild, damit es Tastatureingaben empfängt. Enter ist Start, die Pfeiltasten steuern und die Leertaste ist die Handbremse. Die vollständige Belegung findest du unter Controls.

5. Spielstände speichern und sichern

Speichere im Spiel. Chrome behält den Spielstand beim Neuladen im privaten Speicher für diese Website und dieses Chrome-Profil. Mit Saves → Back up to folder schreibst du bei Bedarf eine datierte ZIP-Datei nach mc3-saves-backup/ in einem Ordner deiner Wahl, auch im entpackten Spielordner. Über Export all saves kannst du die ZIP-Datei herunterladen, falls Chrome im gewählten Ordner nicht schreiben kann.

Zum Wiederherstellen entpacke die ZIP-Datei und wähle vor Play unter Saves → Import save die Datei .mc3Remix oder .mc3 aus UDATA/. Beim Löschen der Websitedaten geht Chromes Kopie verloren. Bewahre die ZIP-Datei separat auf.

Wenn etwas nicht funktioniert

  • Fehlt default.xbe, wähle den Ordner mit dieser Datei und allen Disc-Dateien oder überprüfe deine Kopie.
  • Prüfe bei einem abgelehnten Build oder Datenträger die Edition und verwende die unveränderte default.xbe deiner eigenen kompatiblen Xbox-Disc. Falls emcc fehlt, führe source ~/emsdk/emsdk_env.sh im aktuellen Terminal aus.
  • Falls WebAssembly-Threads fehlen, öffne den Launcher direkt in einer aktuellen Desktop-Version von Chrome und lade die Seite normal neu.

Jouer à Midnight Club 3 sur PC

GitHub Pages héberge le lanceur solo. Chrome utilise les fichiers de votre propre disque Xbox et la compilation correspondante sur votre ordinateur. Le lanceur est en anglais. Les langues du jeu dépendent de votre disque.

Pour la préparation, une seule fois sur Ubuntu 24.04 ou sous Windows avec WSL 2, comptez environ 25 Go d’espace libre pour le SDK, le disque et la compilation. Pour jouer, utilisez un Chrome récent pour ordinateur avec les threads WebAssembly, SIMD, WebGL 2 et assez de mémoire. Si vos fichiers sont prêts, passez à l’étape 4.

Retour au lanceur

1. Copier votre disque Xbox

Utilisez DUB Edition Remix pour la première Xbox (Europe ou États-Unis). La première DUB Edition pour Xbox (Europe ou États-Unis) est également compatible. Un lecteur DVD de PC ordinaire ne voit généralement que la partition vidéo.

  1. Si vous avez déjà une copie complète de votre disque au format ISO ou XISO, utilisez-la à l’étape 3.
  2. Si vous avez le disque et une Xbox équipée d’un tableau de bord alternatif avec FTP, insérez le disque et ouvrez ce tableau de bord. Reliez la Xbox et le PC à votre réseau domestique. Dans un client FTP sur le PC, indiquez l’adresse IP affichée sur la Xbox et ses identifiants FTP. Ouvrez le lecteur DVD D: et copiez tout son contenu. Le dossier copié doit contenir default.xbe à sa racine.
  3. Un lecteur DVD compatible doté d’un micrologiciel adapté peut aussi créer une ISO complète. Sauvegarder ses disques Xbox avec xemu (en anglais)

2. Installer Ubuntu et Emscripten

Sous Windows 10 ou 11, ouvrez PowerShell en tant qu’administrateur et lancez la commande suivante. Redémarrez si nécessaire, ouvrez Ubuntu 24.04 depuis le menu Démarrer et créez votre identifiant et votre mot de passe Ubuntu. Sous Ubuntu, passez au bloc de commandes suivant. Guide WSL de Microsoft

wsl --install -d Ubuntu-24.04

Exécutez ces commandes dans le terminal Ubuntu. Conservez le projet dans votre dossier personnel Ubuntu.

sudo apt update
sudo apt install -y git make
cd ~
git clone https://github.com/sPROFFEs/mc3-web-sites.git
cd mc3-web-sites
make setup GAME=remix

git clone https://github.com/emscripten-core/emsdk.git ~/emsdk
cd ~/emsdk
./emsdk install latest
./emsdk activate latest
source ~/emsdk/emsdk_env.sh
cd ~/mc3-web-sites

Pour la première DUB Edition, utilisez GAME=dub dans chaque commande make. Installation du SDK Emscripten (en anglais)

3. Extraire et compiler le jeu

Si vous avez une ISO, copiez-la dans votre dossier personnel Ubuntu sous le nom mc3.iso et lancez la première commande ci-dessous. Sous Windows, cd ~ && explorer.exe . ouvre ce dossier dans l’Explorateur. Revenez au projet avec cd ~/mc3-web-sites. Si vous avez déjà copié les fichiers du disque, placez-les dans game-remix/ dans le projet. Vérifiez la présence de game-remix/default.xbe et commencez par make lift.

make extract GAME=remix ISO="$HOME/mc3.iso"
make lift GAME=remix
make web GAME=remix

La première conversion et la compilation peuvent prendre plusieurs minutes. Remix produit mcdub3remix.js et mcdub3remix.wasm dans work-remix/build-web/. Pour DUB, le disque va dans game/ et les fichiers mcdub3.js et mcdub3.wasm se trouvent dans work-dub/build-web/.

4. Lancer le jeu

Pour jouer sur un autre ordinateur, copiez le dossier extrait du disque et les fichiers .js, .wasm et, le cas échéant, .worker.js correspondants. Vous pouvez les transférer dans un ZIP et le décompresser sur l’autre ordinateur. La même compilation fonctionne dans Chrome sur les ordinateurs compatibles sous Windows, macOS ou Linux. L’ordinateur de destination peut lancer les fichiers directement.

  1. Revenez au lanceur dans Chrome sur votre ordinateur. À la première visite, la page se recharge une fois pour activer les threads WebAssembly.
  2. Cliquez sur Choose build files et sélectionnez les fichiers .js et .wasm ensemble. Ajoutez le .worker.js correspondant si la compilation l’a créé.
  3. Cliquez sur Choose disc folder, sélectionnez game-remix/ ou game/, autorisez Chrome à lire le dossier et appuyez sur Play. Après un rechargement, refaites les deux sélections. Sous Windows, lancez explorer.exe . depuis le dossier du projet. Si Chrome ne peut pas ouvrir le chemin WSL, copiez les fichiers et le dossier du disque vers un dossier Windows ordinaire. Ouvrir les fichiers WSL dans l’Explorateur

Cliquez sur le jeu pour activer le clavier. Entrée correspond à Start, les flèches permettent de conduire et la barre d’espace actionne le frein à main. Consultez Controls pour la liste complète.

5. Enregistrer et sauvegarder votre progression

Enregistrez votre progression dans le jeu. Chrome la conserve entre les visites dans l’espace privé associé à ce site et à votre profil Chrome. Utilisez Saves → Back up to folder quand vous souhaitez écrire un ZIP daté dans mc3-saves-backup/, dans le dossier de votre choix, par exemple celui du disque extrait. Si Chrome ne peut pas y écrire, utilisez Export all saves pour télécharger le ZIP.

Pour restaurer un profil, décompressez le ZIP et sélectionnez le fichier .mc3Remix ou .mc3 dans UDATA/ via Saves → Import save, avant de cliquer sur Play. Supprimer les données du site efface la copie de Chrome. Conservez le ZIP à part.

En cas de problème

  • Si default.xbe est introuvable, sélectionnez le dossier contenant ce fichier et toutes les données du disque ou vérifiez que la copie est complète.
  • Si le disque ou la compilation est refusé, vérifiez l’édition du jeu et utilisez le default.xbe intact de votre disque Xbox compatible. Si emcc manque, lancez source ~/emsdk/emsdk_env.sh dans le terminal actuel.
  • Si les threads WebAssembly sont indisponibles, ouvrez le lanceur directement dans une version récente de Chrome pour ordinateur et rechargez la page normalement.

Jugar a Midnight Club 3 en tu PC

GitHub Pages aloja el lanzador para un jugador. Chrome usa los archivos de tu propio disco de Xbox y la compilación correspondiente, guardados en tu equipo. El lanzador está en inglés. Los idiomas del juego dependen de tu disco.

Para preparar los archivos una vez, usa Ubuntu 24.04 o Windows con WSL 2 y reserva unos 25 GB para el SDK, la copia del disco y la compilación. Para jugar, usa Chrome de escritorio reciente, con hilos de WebAssembly, SIMD, WebGL 2 y memoria suficiente. Si ya tienes los archivos preparados, ve al paso 4.

Volver al lanzador

1. Copia tu disco de Xbox

Usa DUB Edition Remix para la primera Xbox (Europa o EE. UU.). También sirve la primera DUB Edition para Xbox (Europa o EE. UU.). Una unidad de DVD normal de PC suele leer solo la partición de vídeo.

  1. Si ya tienes una copia completa de tu disco en ISO o XISO, guárdala para el paso 3.
  2. Si tienes el disco físico y una Xbox con un menú alternativo que permite FTP, mete el disco y abre ese menú. Conecta la Xbox y el PC a tu red doméstica. En un cliente FTP del PC, introduce la IP que muestra la Xbox y sus credenciales FTP. Abre la unidad de DVD D: y copia todo su contenido. El archivo default.xbe debe quedar en la raíz de la carpeta copiada.
  3. También puedes crear una ISO completa con una unidad de DVD compatible y con firmware adaptado. Guía de copias de discos Xbox de xemu (en inglés)

2. Prepara Ubuntu y Emscripten

En Windows 10 u 11, abre PowerShell como administrador y ejecuta el siguiente comando. Reinicia si te lo pide, abre Ubuntu 24.04 desde Inicio y crea tu usuario y contraseña de Ubuntu. Si ya usas Ubuntu, pasa al siguiente bloque de comandos. Guía de WSL de Microsoft

wsl --install -d Ubuntu-24.04

Ejecuta estos comandos en la terminal de Ubuntu. Guarda el proyecto en tu carpeta personal de Ubuntu.

sudo apt update
sudo apt install -y git make
cd ~
git clone https://github.com/sPROFFEs/mc3-web-sites.git
cd mc3-web-sites
make setup GAME=remix

git clone https://github.com/emscripten-core/emsdk.git ~/emsdk
cd ~/emsdk
./emsdk install latest
./emsdk activate latest
source ~/emsdk/emsdk_env.sh
cd ~/mc3-web-sites

Para la primera DUB Edition, usa GAME=dub en todos los comandos make. Instalación de Emscripten (en inglés)

3. Extrae y compila el juego

Si tienes una ISO, cópiala a tu carpeta personal de Ubuntu con el nombre mc3.iso y ejecuta la primera orden de abajo. En Windows, cd ~ && explorer.exe . abre esa carpeta en el Explorador. Después, vuelve al proyecto con cd ~/mc3-web-sites. Si ya tienes los archivos extraídos, ponlos en game-remix/ dentro del proyecto. Comprueba que existe game-remix/default.xbe y empieza por make lift.

make extract GAME=remix ISO="$HOME/mc3.iso"
make lift GAME=remix
make web GAME=remix

La primera conversión y compilación pueden tardar varios minutos. Remix genera mcdub3remix.js y mcdub3remix.wasm en work-remix/build-web/. Para DUB, la carpeta del disco es game/ y salen mcdub3.js y mcdub3.wasm en work-dub/build-web/.

4. Abre el juego

Para jugar en otro equipo, copia la carpeta del disco extraído y los archivos .js, .wasm y, si existe, .worker.js de esa compilación. Puedes enviarlos en un ZIP y descomprimirlo en el equipo de destino. La misma compilación sirve en ordenadores compatibles con Windows, macOS y Linux. En el equipo de destino puedes abrirla directamente con Chrome.

  1. Vuelve al lanzador en Chrome de escritorio. La primera vez la página se recarga una sola vez para activar los hilos de WebAssembly.
  2. Pulsa Choose build files y selecciona juntos el .js y el .wasm. Incluye el .worker.js correspondiente si la compilación lo generó.
  3. Pulsa Choose disc folder, selecciona game-remix/ o game/, permite a Chrome leer la carpeta y pulsa Play. Vuelve a seleccionar ambas cosas si recargas. En Windows, ejecuta explorer.exe . desde el proyecto para localizar los archivos. Si Chrome no puede abrir la ruta de WSL, copia los archivos y la carpeta del disco a una carpeta corriente de Windows. Ver archivos de WSL en el Explorador

Haz clic en el juego para activar el teclado. Enter equivale a Start, las flechas sirven para conducir y Espacio es el freno de mano. En Controls tienes la lista completa.

5. Guarda tu partida y haz una copia

Guarda dentro del juego. Chrome conserva la partida entre visitas en su almacenamiento privado para este sitio y ese perfil de Chrome. Cuando quieras una copia, ve a Saves → Back up to folder para escribir un ZIP con fecha en mc3-saves-backup/, dentro de la carpeta que elijas, incluida la del disco extraído. Si Chrome no puede escribir allí, usa Export all saves para descargar el ZIP.

Para recuperar un perfil, descomprime el ZIP y antes de pulsar Play selecciona el archivo .mc3Remix o .mc3 de UDATA/ con Saves → Import save. Borrar los datos del sitio elimina la copia de Chrome. Conserva el ZIP aparte.

Si algo falla

  • Si falta default.xbe, selecciona la carpeta que contiene ese archivo y todos los datos del disco o revisa que la copia esté completa.
  • Si se rechaza el disco o la compilación, comprueba la edición y usa el default.xbe intacto de tu propio disco de Xbox compatible. Si falta emcc, ejecuta source ~/emsdk/emsdk_env.sh en la terminal actual.
  • Si los hilos de WebAssembly no están disponibles, abre el lanzador directamente en una versión reciente de Chrome de escritorio y recarga normalmente.
